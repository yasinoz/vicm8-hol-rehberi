## Bölüm A — Kavramlar (sıfırdan)

### Sanallaştırma nedir?
Bir fiziksel sunucunun CPU, RAM, disk ve ağ kaynaklarını, üstünde **birden çok
bağımsız "sanal makine" (VM)** çalıştıracak şekilde bölmektir. Her VM kendi
işletim sistemini çalıştırır ama hepsi aynı donanımı paylaşır. Bunu yapan
yazılıma **hypervisor** denir.

### vSphere = ESXi + vCenter
vSphere tek bir ürün değil, bir **platformdur**. İki ana bileşeni var:

| Bileşen | Nedir | Rolü |
|---|---|---|
| **ESXi** | Fiziksel sunucuya kurulan **hypervisor** | VM'leri **çalıştırır** (CPU/RAM/disk/ağ verir) |
| **vCenter Server** | Merkezi yönetim sunucusu | Tüm ESXi host'larını ve VM'leri **tek yerden yönetir** |

> Benzetme: **ESXi = işçi** (asıl işi yapar), **vCenter = yönetici** (kimin ne
> yapacağına karar verir, hepsini koordine eder). Bir ESXi'ye doğrudan da
> bağlanabilirsin ama kümeler, vMotion, HA/DRS gibi özellikler **vCenter**
> gerektirir.

### vSphere Client
vCenter'ı yönettiğin **web arayüzü**. Tarayıcıdan `https://<vcenter>/ui`
adresiyle açılır. Soldaki ağaç **envanterdir**: Datacenter → Cluster → Host →
VM hiyerarşisi.

### Envanter hiyerarşisi
```
vCenter
└─ Datacenter (mantıksal sınır)
   └─ Cluster (ESXi host grubu — HA/DRS buraya uygulanır)
      ├─ ESXi Host 1
      ├─ ESXi Host 2
      └─ VM'ler
```

> **8 ↔ 9.1 farkı:** VCF 9.1'de yönetim arayüzü "VCF Operations / vSphere
> Client" olarak biraz yenilenmiştir; mantık (Datacenter→Cluster→Host→VM)
> **aynıdır**.

## Bölüm B — HOL Lab'ı: HOL-2706-01 (What's New: Compute)

**Bu lab ne yapar?** vSphere'in VCF 9.1'deki güncel halini ve yeni
özelliklerini gezer: memory tiering, vCenter quick patch, ESX live patch,
geliştirilmiş DRS, config profiles. Senin için bugünkü değeri: **güncel
vSphere Client arayüzünü ve envanteri canlı görmek.**

### Yapılacak modüller (bugün)
- **Module 1 — Summary of What's New (Beginner, ~15 dk):** Genel bakış; yeni
  özelliklerin listesi. Arayüzü tanı, envanterde gez.
- *(İsteğe bağlı)* **Module 2 — Memory Tiering (Intermediate):** Zaman kalırsa;
  ileri bir konu, ICM temelinin dışında.

### Türkçe adım özeti (Module 1)
1. Lab başlayınca masaüstünden **vSphere Client**'i aç (tarayıcı kısayolu).
2. Soldaki **envanter ağacını** incele: Datacenter, Cluster, Host'lar, VM'ler.
   Hiyerarşiyi Bölüm A'daki şemayla eşleştir.
3. Bir **ESXi host**'a tıkla → **Summary**: CPU/RAM/sürüm/uptime. "Bu host
   neyi çalıştırıyor?" diye bak (VMs sekmesi).
4. Bir **VM**'e tıkla → **Summary**: hangi host'ta, kaç vCPU/RAM, güç durumu.
5. Rehberin (sağ panel) gösterdiği **yeni özellik** ekranlarını takip et;
   amaç ezber değil, **arayüzde nerede ne var** onu oturtmak.

> **Not alın:** "vCenter nerede, host nerede, VM nerede" — bu üç şeyi
> gördüğünde günün temel hedefi tamam demektir.

## Bölüm C — Eğitmen lab demosu (tam adımlar)

> Bu akış **vSphere 8 eğitmen lab'ında** canlı yapılır (HOL'de bu "sıfırdan"
> adımlar yoktur). Öğrenci izler, kendi notunu/ekran görüntüsünü alır.

### C.1 — ESXi kurulumu (DCUI üzerinden)
1. Sunucuyu ESXi **ISO**'su ile başlat (USB / CD / iLO-iDRAC sanal medya).
2. Açılış menüsünden **ESXi Installer** → yükleyici belleğe açılır.
3. **Welcome** → **Enter**; EULA → **F11** ile kabul.
4. **Select a Disk:** kurulacak yerel diski seç → **Enter**.
5. **Keyboard layout** → **Enter**.
6. **Root password** belirle (iki kez, güçlü) → **Enter**.
7. **F11** ile kurulumu onayla. Bitince medyayı çıkar → **Enter** ile **reboot**.
8. Açılınca **DCUI** (sarı/gri ekran) gelir → **F2** → root parolası ile gir.
9. **Configure Management Network**:
   - **Network Adapters:** doğru fiziksel NIC'i seç.
   - **VLAN (optional):** gerekiyorsa yönetim VLAN'ı.
   - **IPv4 Configuration → Set static IPv4:** IP / alt ağ maskesi / gateway.
   - **DNS Configuration:** DNS sunucu(lar) + bu host'un **FQDN**'i.
10. **Esc → Y** ile kaydet. **Test Management Network** ile gateway ping + DNS
    çözümlemesini doğrula.
11. Tarayıcıdan **https://\<esxi-ip\>/ui** → **Host Client**'a root ile gir
    (host tek başına yönetilebiliyor; asıl yönetim vCenter'dan olacak).

### C.2 — vCenter'a Datacenter / Cluster / Host ekleme
1. **https://\<vcenter\>/ui** → **vSphere Client**'a
   `administrator@vsphere.local` ile gir.
2. En üstteki **vCenter** nesnesine sağ tık → **New Datacenter** → ad: `DC-HQ`.
3. `DC-HQ` sağ tık → **New Cluster** → ad: `Cluster-HQ`; HA/DRS'yi **şimdilik
   kapalı** bırak (Gün 5'te açacağız) → **Finish**.
4. `Cluster-HQ` sağ tık → **Add Hosts**:
   - Host **FQDN/IP** + **root** kimliği (birden çok host girilebilir).
   - **Sertifika/thumbprint** uyarısını kabul et.
   - Özet → **Finish**. Host yeşil görünür.
5. Host → **Summary**: CPU/RAM/ESXi sürümü/uptime doğru mu kontrol et.

### C.3 — İlk sanal makineyi oluşturma
1. `Cluster-HQ` sağ tık → **New Virtual Machine** → **Create a new virtual
   machine** → **Next**.
2. **Name and folder:** `web01` + Datacenter.
3. **Compute resource:** cluster/host (uyumluluk yeşil olmalı).
4. **Storage:** bir **datastore** seç.
5. **Compatibility:** en yeni ESXi sürümü (en çok özellik).
6. **Guest OS:** aile + sürüm (doğru varsayılan donanım/sürücü için önemli).
7. **Customize hardware:**
   - **CPU** ve **Memory** değerleri.
   - **New Hard disk:** boyut + **Thin/Thick** provisioning.
   - **New Network:** bir **port group** seç (Gün 2'de oluşturacağız; şimdilik
     "VM Network").
   - **New CD/DVD Drive → Datastore ISO File:** OS ISO'sunu seç, **Connect At
     Power On** işaretle.
8. **Finish**.
9. VM → **Power On** → **Launch Web Console** → OS kurulumunu başlat; kurulum
   sonrası **VMware Tools**'u kur (ağ/performans/konsol için şart).
